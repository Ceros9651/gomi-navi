# pwa-install Specification

## Purpose

iPhoneのホーム画面から1タップでアプリのように起動でき、通信がなくても動き、公開したデータ更新が自動で反映されるようにする。

## Requirements

### Requirement: ホーム画面からの起動

システムは、iPhone Safariの「ホーム画面に追加」で専用のアイコンと名前（ごみナビ）で追加でき、ホーム画面から開いたときにブラウザのUIなしの全画面表示で起動しなければならない（SHALL）。画面の内容はノッチやホームインジケーターに隠れてはならない（SHALL NOT）。

#### Scenario: ホーム画面に追加して起動
- **WHEN** Safariで公開URLを開き、共有メニューから「ホーム画面に追加」して、そのアイコンから開く
- **THEN** 「ごみナビ」のアイコンで追加され、アドレスバーのない全画面で今日と明日が表示される

### Requirement: オフライン動作

一度表示したことがある端末では、システムはネットワークに接続していなくても起動し、今日と明日を表示できなければならない（SHALL）。

#### Scenario: 機内モードで起動
- **WHEN** 一度アプリを開いた後、機内モードにしてホーム画面から開く
- **THEN** 通常どおり今日と明日が表示される

### Requirement: 自動更新

新しいバージョンが公開されたとき、システムはユーザーの操作なしにそれを取得し、遅くとも次回以降の起動で新しいバージョンを表示しなければならない（SHALL）。

#### Scenario: 例外日データの更新
- **WHEN** 例外日データを追加した新しいバージョンが公開された後、オンラインの状態でアプリを開き、その後もう一度開く
- **THEN** 2回目までに新しいデータで表示される

### Requirement: ホーム画面追加の案内

Safariのブラウザ画面で開いたとき（ホーム画面から起動していないとき）、システムは「共有ボタン →『ホーム画面に追加』」の手順を短く案内し、閉じるボタンで閉じられるようにしなければならない（SHALL）。閉じた後は同じ端末で再び表示してはならない（SHALL NOT）。ホーム画面から起動したときは表示してはならない（SHALL NOT）。

#### Scenario: Safariで初めて開く
- **WHEN** Safariで公開URLを初めて開く
- **THEN** ホーム画面追加の案内が表示される

#### Scenario: 案内を閉じる
- **WHEN** 案内を閉じた後、Safariで再び開く
- **THEN** 案内は表示されない

#### Scenario: ホーム画面から起動
- **WHEN** ホーム画面のアイコンから開く
- **THEN** 案内は表示されない
