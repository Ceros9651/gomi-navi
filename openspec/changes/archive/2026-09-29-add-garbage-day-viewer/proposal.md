# Proposal

## Why

春日井市のごみ出しカレンダーはA4のPDFで、「今日は何のごみの日か」を知るには毎回PDFを開いて日付を探す必要がある。E地区に住む自分と家族が、iPhoneのホーム画面から1タップで「今日」と「明日」に出せるごみを確認できるようにしたい。

## What Changes

- 春日井市 E地区の収集ルール（曜日・第n曜日）と年版ごとの例外日（年末年始の収集なし・特別収集）を、2026年版カレンダーに基づいてデータとして持つ
- アプリを開いた日（今日）と翌日（明日）に出せるごみの種類を、PDFと同じ色・自作アイコン・種類名で表示する。品目例はタップで開く
- 朝8時以降は今日の分を「締め切り済み」と表示する
- カレンダーの範囲外（2027年以降など）の日付は、ルールから推定して「推定（未確認）」と明示して表示する
- iPhone Safari向けのPWAとして提供する（ホーム画面追加、オフライン動作、自動更新、Safariで開いたときのホーム画面追加案内、ダークモード対応）
- GitHub Actions で GitHub Pages（https://ceros9651.github.io/gomi-navi/）へ自動デプロイする

対象外：他地区の選択、通知（リマインダー）、今日・明日以外の日の閲覧。

## Capabilities

### New Capabilities

- `collection-schedule`: E地区の収集ルールと例外日から、任意の日付に出せるごみの種類（および推定かどうか）を判定する
- `daily-view`: 今日と明日のごみの種類を表示する画面（色・アイコン・品目例・収集なし・締め切り済み・推定表示・ダークモード）
- `pwa-install`: iPhoneのホーム画面から起動できるPWAとしての振る舞い（オフライン動作、自動更新、ホーム画面追加の案内）

### Modified Capabilities

（なし）

## Impact

- 新規コード：`src/` 配下（収集日判定、画面描画、スタイル、アイコン）、`public/` 配下（アプリアイコン）
- 依存：`vite-plugin-pwa`、`vitest`（導入済み）
- 設定：`vite.config.ts`（PWA設定）、`.github/workflows/`（Pagesデプロイ）
- 外部：GitHub リポジトリ `Ceros9651/gomi-navi` の Pages 設定（ソースを GitHub Actions にする）
- 運用：毎年、市の新しいカレンダーPDFが出たら例外日データを追加する
