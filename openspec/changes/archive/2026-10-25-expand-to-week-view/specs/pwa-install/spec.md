# Spec Delta

## MODIFIED Requirements

### Requirement: ホーム画面からの起動

システムは、iPhone Safariの「ホーム画面に追加」で専用のアイコンと名前（ごみナビ）で追加でき、ホーム画面から開いたときにブラウザのUIなしの全画面表示で起動しなければならない（SHALL）。画面の内容はノッチやホームインジケーターに隠れてはならない（SHALL NOT）。

#### Scenario: ホーム画面に追加して起動
- **WHEN** Safariで公開URLを開き、共有メニューから「ホーム画面に追加」して、そのアイコンから開く
- **THEN** 「ごみナビ」のアイコンで追加され、アドレスバーのない全画面で今日から1週間分が表示される

### Requirement: オフライン動作

一度表示したことがある端末では、システムはネットワークに接続していなくても起動し、今日から1週間分を表示できなければならない（SHALL）。

#### Scenario: 機内モードで起動
- **WHEN** 一度アプリを開いた後、機内モードにしてホーム画面から開く
- **THEN** 通常どおり今日から1週間分が表示される
